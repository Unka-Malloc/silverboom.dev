# Silverboom documentation

The site is a single static page:

- `index.html` — structure and copy: hero, member rack, architecture axes,
  field notes.
- `site.css` — the silver/gunmetal design system.
- `site.js` — hero trajectory animation and the rack dossier interaction.
- `assets/fonts/` — self-hosted variable fonts (Funnel Display, Funnel Sans).
- `favicon.svg` — bullet mark.
- `dns/` — reviewed Cloudflare DNS import for `silverboom.dev`.

Member repository links point at `github.com/Unka-Malloc`.
